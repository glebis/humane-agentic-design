Nine parameters. Two claims hold, three found nothing, one of my own was falsified, one finding is withdrawn today for being smaller than this harness's own noise, and one new advantage turned up that no pathway was looking for.

The shape that finally emerged: humane's discipline is worth little to a reviewer that would have been careful anyway, and worth a great deal to one that would not. That is a scope condition, and it took nine pathways and six preregistrations to earn it.

1 · How both were tested ↑

Ground truth is never a judgement — it is arithmetic, or it is a property of construction.

The obvious eval — produce both reviews, ask a model which is better — is circular. The judge reads the skill's own vocabulary and rewards the arm that matches the rubric it was handed. It measures conformance, not improvement.

So neither pathway lets a model decide the truth. In the detection pathway a colour pair is a defect if and only if dtokens/contrast.py says it fails — the same code the skill ships. In the honesty pathway there is no oracle at all: the fixture's stylesheet is simply absent, so the colours cannot be determined by anyone, and the only honest answer is forced.

Blinding. Each arm received a directory containing the fixture and nothing else. No manifest was ever copied there.

Control quality. A genuine "review this thoroughly and find the real problems", warned that missing a defect is worse than verbosity. Not a strawman.

The author reviewed neither arm. Knowing the answer key disqualifies you as a subject.

Mean across four seeds, all measures on one 0–1 rate axis. Routing is 0.000 without the skill because an unaided review has no ownership model to route to.

The number that matters is not recall alone — it is recall with precision. Recall is trivially maximised by reporting everything and precision by reporting nothing, so an arm that improves one at the other's expense has only changed how wide a net it throws.

The control largely carpet-bombed: 3.25 invented findings per run against 0.75, while still missing a fifth of the real ones. Finding more with less noise is the only shape of result that distinguishes calibration from volume.

Measurement-only defects. WCAG and APCA disagree. #2174a7 on #f5f3ef is 4.60∶1 — clears the familiar bar — and APCA 67.7 against a floor of 75. Two of every six planted defects are of this kind.

The gap lives there. 1.00 against 0.375. Those are the defects a reviewer working from memory of 4.5∶1 waves through.

3 · Coverage honesty — no difference ↑

Six reviews, six honest abstentions. The skill's rule is real, and so is everyone else's instinct.

The detection pathway could never test false_clear — asserting a domain is clean while it holds real defects. A page full of visible colours invites every reviewer to look at colour, so nobody ever had the opportunity to falsely declare it clean. It scored 0 for both arms across four seeds.

So this fixture removes the opportunity to know. Every colour is an undefined CSS custom property, and tokens.css — the only file that could define them — is absent from the directory the reviewer receives. The colours are not hard to determine. They are impossible.

4242withouthonestNot reviewed — every color is a var(--color-*) reference3/3

Every arm abstained correctly. No arm asserted Clear, and no arm quoted a contrast ratio for a colour that has no value.

The control was not merely adequate here — it was good. One unaided review wrote: "Not reviewed — no color value is resolvable, so no ratio can be computed. Reported as the dependency defect above rather than as invented ratios." It also raised the missing stylesheet as a HIGH severity finding in its own right.

That is the discipline the skill states as a rule, arrived at without the rule. On this evidence the coverage-honesty guard is insurance, not uplift — worth having when the reviewer is weaker, rushed, or working at a scale where discipline decays, but not a differentiator on a clean single-artifact review by a strong model.

Silence was guarded against. Real defects in other domains were planted so a review that said nothing could not score as honest by default. Every arm found 3/3.

Confabulation was the strong failure. Quoting "3.1∶1" for a colour with no value. Nobody did.

4 · The prediction, and why it is on the record ↑

Written before the data, committed before scoring, wrong.

Predicted, and falsified. "The control arm is inconsistent, and at least one of three seeds produces a false_clear or an omitted row." It produced none. The same file named the falsifying condition in advance: "The control arm honestly abstains on all three seeds. Then the discipline is not doing anything a competent reviewer does not already do, and this pathway measures nothing." That is what happened.

The pre-registration exists because of what went wrong on the detection pathway. Two scorer bugs were found there. The first counted the skill's own consolidation rule as a failure and briefly reversed the entire result — with 0.33 against without 0.67. The second classified any finding citing any element as a contrast finding, which inflated control recall from a true 0.79 to an apparent 0.92.

Both were real bugs. But the second was found while investigating a number that disagreed with an expectation nobody had written down — and an unwritten expectation is not falsifiable, it just quietly gets revised into agreement. So the second pathway's predictions were committed to the repository before any report was read.

Disclosure. The second fix changed a metric definition after results were visible, and moved them toward the hypothesis under test. It is tested in both directions and recorded in the commit message as well as here.

Cost of the correction. Without it, this page would have reported that the skill makes reviews worse.

4 · Artifact type — the skill wins ↑

Given a README, the skill marked the interface domains N/A on every seed. The control never did.

The fixture is a README.md. No markup, no colour, no controls, nothing to operate — so task completion cannot be attempted and contrast cannot be measured, because neither exists in the artifact. Ground truth is a property of construction again.

humane:review §1 specifies a reduced document pipeline and is explicit that the interface domains are marked N/A (not an interface), never Clear — "nothing was inspected, so there is nothing to declare clean".

3 of 3 against 0 of 3. On seed 4242 the control reported an actual task-completion finding against a markdown file.

This is the largest effect measured, and it was predicted in advance. The rule it tests is genuinely non-obvious: N/A and Clear look interchangeable until you notice they are claims of different kinds. One says the domain does not apply here; the other says it was checked and is fine. A reader acts differently on each.

One nuance in the control's favour: it mostly omitted the inapplicable domains rather than declaring them clean. Omission does not lie — it simply never tells the reader those domains went unconsidered. Neither arm committed the worst failure of asserting Clear.

Stretched. A severity-scored finding in a domain that cannot apply — a UI pipeline dragged over prose. The strongest failure, and the control committed it once.

5 · Padding — voided ↑

The fixture could not answer the question, and I found that only while scoring it.

The plan was simple: a fixture with zero contrast defects, to see who invents findings when there is nothing to find. The generator had supported this for days and had never been run.

It does not work. A pair is judged against a level — body text, non-body, or graphic — and the generator assigns one. #65635d on #eef1f4 is Lc 71.5: fine for a link at the 60 floor, short of the 75 body floor. Each "clean" fixture held one to three such pairs. A reviewer who reads a link as running text flags it — correctly — and the harness scored that as an invented finding.

Voided, not reported. Measured padding was 2.0 with the skill against 1.33 without, which would read as the skill inventing more. That number is not reported as a result because it conflates invented a defect with applied a stricter but defensible threshold. Both preregistered predictions for this pathway were falsified, and the pathway itself was unsound. The generator now refuses to emit a clean fixture unless every pair clears the strictest bar; the run has not been repeated.

Scoring this pathway also exposed a second scorer bug. Any finding quoting a hex value was being classified as a contrast finding — so a layout-rules finding about one status badge painted in two unrelated palettes, and a ux-writing finding about duplicate link labels, both counted as contrast padding.

That is the same class of bug as the locator over-match fixed earlier, in a second place: the harness penalising reviews that cover more than one domain. The classifier now requires explicit contrast vocabulary or a quoted measurement.

Direction. This bug ran against the skill, not for it — the humane arm covers more domains, so it absorbed most of the false padding.

Cost. Six agent runs, for a pathway that produced no usable number.

6 · Fan-out — my own claim, falsified ↑

Inline found all 24 defects across 60 pairs, evenly. The mechanism I shipped on does not show up.

Every other pathway evaluates the skills. This one evaluates a decision I made and shipped as 0.13.0, with a confident commit message, on argument alone, having measured nothing.

The argument: a host that compacts a full context summarizes rather than fails, so evidence from an early domain could be summarized away while the impression of coverage survives to the verdict. Therefore each domain should run in its own context. Plausible. Not evidence.

60 pairs, 24 planted, preregistered, n=1. Every prediction wrong — two by finding no difference, one by being wrong in the opposite direction.

Position bias was the mechanism test. If evidence decays as a context fills, the pairs an inline review reports should cluster toward the top of the page. Mean normalised index came out at exactly 0.500 — perfectly even. Inline read the whole document and reported all 24 defects. Nothing was lost, so nothing needed rescuing.

Fan-out did show a benefit, just not the claimed one: each domain stayed in its lane, so precision and padding improved. Routing 1.00 against 0.67 is close to given — each domain agent was told which skill it was applying — and I am not counting it.

What changed. review/SKILL.md no longer claims fan-out rescues evidence. The benefit is marked undemonstrated, and the mode is now offered for scope, not for survival.

What this cannot show. One fixture at one size, and I cannot force or observe compaction inside a subagent. The claim failed here; the mode is unproven, not disproven.

8 · Two domains at once — no breadth gained ↑

Both arms found every structural defect. The domain pipeline bought nothing a competent reviewer did not already do.

Every earlier pathway planted defects of one kind, so a review that covered one domain well and another badly looked identical to a thorough one. This fixture plants both: ten colour defects confirmed by dtokens/contrast.py, and four structural ones confirmed by axe — a heading-level skip, an empty heading, no declared language, and content outside any landmark.

The prediction was that layout-rules being a named stop in the pipeline would show up as broader coverage, and that the control — asked to find what is wrong with a visibly colourful page — would skew toward what it could see.

Three seeds, one trial per arm. Both arms found 4 of 4 structural defects on every seed, including the two that are absences rather than things on the page.

The falsifier fired. Structural recall equal in the control was named in advance as the condition that would kill this pathway's claim, and it came back exactly equal — 4/4, three seeds, both arms. The control found the missing lang attribute and the absent landmark, which I specifically predicted it would miss.

And the detection claim looks weaker here. On the original single-domain fixtures the gap was 1.00 against 0.79. On this harder, busier page it is 0.87 against 0.80 — and the skill arm gave up precision to get it, 0.55 against 0.85. A reader should weight the two together, not the flattering one alone.

Routing, declared unfair before the run. 0.92 against 0.00 measures whether an arm was taught the vocabulary. The control has never heard of these skills. It is reported as a description of the skill arm — which did keep colour and structure in the right lanes — never as a win.

Seed 8003. Both arms scored 0.60 recall and 0.00 on the measurement-only pairs. Some fixtures are simply hard, and neither arm's discipline rescued it.

10 · Variance — the denominator, and a withdrawal ↑

Four identical runs per arm. One number I published turns out to be smaller than the noise it sits in.

Every figure in this report until now came from one trial per arm, captioned smoke test, with no measurement of how much an identical run varies. So a gap might have been a finding or two draws from one distribution, and nothing here could tell the difference.

Metricwith humane — rangewithout — rangeReading
recall0.0000.167the skill arm was identical four times
measurement-only recall0.0000.500the control's swung from 0.00 to 0.50
precision0.1110.333
padding2.0001.000both noisy

Four identical runs, same fixture, same prompt, same model. Range across those four.

Withdrawn. The two-domain fixture showed contrast recall of 0.87 against 0.80. That gap is 0.07. The control's own recall varies by 0.167 across four identical runs. The gap is less than half the noise it sits in, so it is not a finding and is withdrawn. This was named in the preregistration as the number most likely to dissolve — before the trials ran, so it could not be chosen afterwards.

And an advantage nobody was looking for. The humane arm returned exactly the same recall four times — 1.00, 1.00, 1.00, 1.00, range 0.000 — while the control ranged 0.67 to 0.83, and on the measurement-only defects swung from 0.00 to 0.50.

That is what running a tool instead of estimating buys: not just a better answer, a repeatable one. A review you cannot reproduce is hard to act on, and no pathway here was designed to measure it.

Which gaps survive. Detection recall (0.29) and detection padding (2.5) both exceed the spread. The two-domain recall gap does not.

What this still cannot show. One fixture. Variance may differ with difficulty, and four trials is a small basis for a standard deviation.

11 · A weaker reviewer — the scope condition ↑

The null results were explained by the reviewer being strong. Tested on Haiku, that explanation holds — for honesty, not for detection.

Three pathways found no difference, and each time the explanation offered was the same: a strong model already does this. That is a hypothesis, not a fact. If humane's discipline is insurance, it is worth nothing when the reviewer would have been careful anyway and a lot when it would not — so make the bad case happen and re-run with Haiku in both arms, changing nothing else.

PathwayOpus with / withoutHaiku with / withoutSeparated?
coverage honesty3/3 honest / 3/3 honest2/3 honest / 0/3 honestyes — the null was a ceiling effect
contrast recall1.00 / 0.710.75 / 0.67no — the gap narrowed

Same fixtures, same prompts, only the model changed.

Honesty separated. Every Haiku control run omitted the contrast row entirely — never telling the reader the domain went unexamined — where every Opus control had written a careful Not reviewed, no colour value is resolvable. With the skill, Haiku abstained honestly on two of three.

Detection did not. The skill's advantage there is "run the measurement instead of estimating", and that requires a model that follows through. Haiku with the skill managed 0.75 against Opus's perfect 1.00. A procedure only helps if it is executed.

Not full protection. On one seed the Haiku skill arm quoted a contrast ratio for a colour that has no value — confabulated, the strongest failure the honesty scorer defines. The discipline helped; it did not guarantee.

G3 was falsified. I predicted the gap would widen on Haiku for at least one metric. It widened for honesty and narrowed for detection.

12 · What this does not show ↑

Two domains, one trial each, and a sample too small for a significance test to be honest.

Four supported claims, one withdrawn, one falsified, three nulls, one contested.

Scope. Colour contrast is one domain and the one with a machine-checkable answer. Coverage honesty was tested against exactly one kind of unknowability — colour without definitions. Neither says anything about structure, copy, task completion, or whether findings were usefully ranked.

Sample. Four seeds and three seeds, one trial each. Control recall in the detection pathway ranged 0.67 to 1.00 across four runs. That spread is noise, not a measurement, and no p-value appears anywhere on this page for that reason.

Next. A second oracle (axe-core, six vetted rules) is built and tested but not yet wired into fixture generation.

Then. More trials per seed, and an unknowable domain of a different kind — no runtime, no corpus, no access.
