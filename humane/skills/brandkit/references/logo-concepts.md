# Logo concepts

The standard the mark must meet, and five methods for arriving at one.

## The standard

A brand-kit logo is simple, memorable, symbolic, scalable, ownable, visually
balanced, connected to the brand idea, and usable as icon, wordmark, badge, UI
mark, and pattern.

It should feel like it came from **research and reduction** — not from picking a
shape that looked nice.

Avoid:

- generic lightning bolts, unless strongly justified
- random animals
- fake luxury crests
- copied famous marks
- overcomplicated symbols
- clipart-style icons
- meaningless sparkles
- inconsistent variants across panels

## Methods

Use one. Combine two at most — a mark carrying three ideas carries none.

### 1. Monogram + meaning

Combine the brand initial with a metaphor.

- `K` + kite / frame / direction
- `N` + path / folded system
- `S` + sound wave / speech flow
- `A` + ascent / architecture / momentum

Do not settle for a letter in a box. Use negative space, cuts, folds, or
geometry to make the letter *do* something.

### 2. Product action

Turn the product's main verb into a symbol.

| Action | Symbol direction |
| --- | --- |
| build | frame, scaffold, block, cursor |
| protect | shield, boundary, watch mark |
| convert | switch, arrow, transformation shape |
| speak | waveform, mic, pulse |
| hunt threats | eye, raptor, radar, trace |
| automate | loop, handoff, path |

Keep it abstract and premium, never literal.

### 3. Metaphor fusion

Combine two meaningful ideas into one reduced mark:

- owl + drone vision
- shield + mountain
- moon + waveform
- dog + compliance seal
- dice + mobile game economy
- cursor + lightning speed
- kite + product frame

The fusion should be subtle and readable at a glance. If it needs explaining,
it is two logos wearing one coat.

### 4. Negative space

Use empty space to create intelligence: a hidden arrow, a protected center, a
cutout initial, an internal path, a folded corner, an eye formed by crossing
shapes. Negative space must be crisp — a soft or ambiguous void reads as a
mistake rather than a device.

### 5. Construction geometry

Build the mark from a visible system: circles, diagonal cuts, grids, frames,
modular blocks, layered cards, orbital paths, crosshairs, measured linework.

When you use this method, spend one panel showing the construction logic — it is
the most persuasive panel on the board.
