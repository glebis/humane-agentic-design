# Visual modes

Eight worlds to pick from, chosen by what the brand *is* — not by taste. Each
gives you the panel palette, the texture language, the logo logic that fits, and
the mood to hold. Pick one and commit; a board that hedges between two modes
reads as neither.

---

## Dark developer / builder

**For:** developer tools, coding agents, infra, automation, AI builders.

- Near-black panels, monospace accents, command lines, terminal windows, prompt bars
- Subtle grid; cyan, blue, coral, or lime accents
- Pixel or CRT texture where it fits

**Logo logic:** cursor + frame · bolt + build speed · scaffold + monogram ·
terminal glyph + symbol · modular construction mark

**Mood:** precise, sharp, confident, builder-native.

---

## Dark product / operator

**For:** business tools, growth tools, sales agents, automation, productivity.

- Black / dark red / amber; glowing UI chips, card systems, segmented flows
- Icon rows, reward and progress motifs, minimal hero text

**Logo logic:** signal · gift · path · operator mark · switch · loop · command system

**Mood:** fast, operational, tactical, premium.

---

## Dark nature / calm system

**For:** strategy, travel, wellness, climate, quiet premium SaaS.

- Deep green with a lime accent; misty landscapes, image UI circles, soft overlays
- Calm page labels on a dark editorial grid

**Logo logic:** path · leaf · moon · horizon · compass · portal · folded mark

**Mood:** calm, trustworthy, focused.

---

## Dark security / threat intelligence

**For:** security, compliance, monitoring, network products.

- Black / navy; shield forms, radar lines, threat labels, subtle motion traces
- Red and blue alert chips, controlled gradients

**Logo logic:** shield · raptor · eye · watch · boundary · protected core

**Mood:** serious, vigilant, precise.

---

## Light editorial / compliance

**For:** legal, privacy, compliance, documents, trust brands.

- Warm ivory, paper texture, small serif labels, seals and badges
- Color wheel or palette object, calm stationery; deep blue, red, gold accents

**Logo logic:** seal · dog · shield · document · stamp · monogram

**Mood:** trustworthy, refined, institutional but modern.

---

## Luxury / beauty / fashion

**For:** beauty, fashion, hospitality, premium services.

- Ivory / stone / espresso; serif wordmark, elegant monogram
- Paper grain, embossing, product labels, editorial crops, soft shadows

**Logo logic:** monogram · seal · petal · vessel · ritual object · refined typographic mark

**Mood:** tasteful, adult, expensive.

---

## Voice / communication

**For:** voice AI, chat, assistants, speech, audio.

- Dark indigo with a lilac glow; waveform, mic motif, phone crop, command input, app icon

**Logo logic:** wave + initial · sound orb · speech path · microphone abstraction · pulse ring

**Mood:** fluid, intelligent, intimate.

---

## Cultural / experimental

**For:** music, creative tools, events, gaming-adjacent, cultural products.

- Halftone, CRT texture, analog print, one bold accent color
- Poster-style panels, unexpected image crops, a simple but punchy logo

**Logo logic:** custom wordmark · icon with attitude · symbolic mascot · print-inspired mark

**Mood:** memorable, creative, still controlled.
